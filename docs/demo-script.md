# MICO demo script

1. Start the stack and open `http://localhost:3000`; show the dashboard cards.
2. In Discord, ask MICO to add a project task and set a short reminder.
3. Add a service monitor and show the dashboard health state.
4. Ask for today's GitHub commits, then show a GitHub webhook notification.
5. Request a destructive PC action, show the confirmation code, then cancel it.
6. Send a short audio attachment and show MICO's transcript and MP3 reply.
7. End on the dashboard activity feed and `pytest -q` output.
